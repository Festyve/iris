# Tools, libraries and galleries that fight "AI slop"

Collected from the X posts in [[X posts]]. Use these as places to look before designing, and as vocabulary when briefing.

## Inspiration galleries
| Site | What it is |
|---|---|
| https://land-book.com | Landing page gallery, well curated |
| https://recent.design | Web design gallery |
| https://landdding.com | High-end landing pages |
| https://godly.website | Award-level, motion-heavy websites |
| https://60fps.design | Mobile UI animation gallery |
| https://fontinlogo.com | Fonts used by known brands |
| https://saaspo.com | SaaS web design inspiration |
| https://motionsites.ai | 800+ 3D/motion website prompts (also an MCP at studio.motionsites.ai/mcp) |

## Component and effect libraries
| Library | Use it for |
|---|---|

| https://scrolltide.co | 600+ prompts with code for 3D and scroll sites |
| https://scrollshaders.com | Shader backgrounds for heroes (code, video or image) |
| https://animata.design | 157+ free animated React components |
| https://audiocn.dev | Audio UI parts: mixers, meters, faders |
| https://horizonx.so | Premium UI library |
| https://grainient.supply | Grainy gradient assets |
| https://uiarc.dev | Arc UI components |
| https://bencho.dev | Component library |
