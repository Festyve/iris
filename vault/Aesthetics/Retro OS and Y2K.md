# Retro OS and Y2K

Win95/98 and classic Mac OS UI revival (bevelled grey windows, teal desktops, title bars, pixel icons), pixel-art game UI and Y2K personal-web collage. Many items are UI kits and styleguides of retro components. Others are full desktops, game title screens and cluttered fan-site layouts.

## Type

Bitmap/pixel fonts and MS Sans Serif-style system type. Chunky pixel display caps on buttons (PLAY, CONTINUE). Some Y2K pieces use condensed or stretched display faces.

## Signature moves

- Bevelled 3D window chrome with title bars, close boxes and OK/Cancel buttons
- Pixel icons and cursors (hourglass, folders, recycle bin)
- Chunky pixel buttons with stepped borders for game menus
- Desktop metaphor: teal background, taskbar, start menu
- Y2K cluttered collage: globe graphics, chrome, sticker clutter
