# Expressive work in a disciplined shell

The earlier portfolio study observed a spatial gallery, compact navigation and graphic project panels, with a flatter recruiter presentation at https://www.zirui.ca/recruiter/. These are observations and interpretations, not a claim to know all of the designer's intentions. The live site may change.

## Mechanisms to adapt

- Let specific project material carry the expressive identity; keep the surrounding controls predictable.
- Use scale and value to establish a clear hierarchy before adding effects.
- Give spatial exploration an efficient index alternative.
- Make motion explain continuity and interaction. Support interruption, pause and reduced motion.
- Use preview media deliberately, with posters and clear manual controls.

## Application to Second Cursor

Reference thumbnails and the live canvas should provide character. Keep the library navigation and assistant controls readable and stable. Make cursor motion explain which task changed which artifact.
